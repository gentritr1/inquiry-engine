# The Inquiry Logs

*Companion to The Book of Inquiry. Two logs. The book says calibration
matters and failure is data; these make that executable. If these stay
empty while the book is reread, the book has become decoration.*

------------------------------------------------------------------------

## Calibration Review

Run monthly for fast predictions, yearly for slow ones. Bucket resolved
predictions by stated probability and compare:

| Stated probability | # predictions | # came true | Actual rate |
|---|---|---|---|
| ~60% | | | |
| ~70% | | | |
| ~80% | | | |
| ~90% | | | |
| ~95%+ | | | |

**Reading the table:** if the 80% row comes true ~80% of the time, the
instrument is calibrated. If 90% claims come true 70% of the time, the
instrument is overconfident — the most common defect, and trainable
only by seeing this table regularly. Note the direction of error and
carry it into the next month's probability estimates.

## Quarterly Failure Review

Once a quarter, read the whole failure log in one sitting and answer:

1. Which diagnosis category recurs most? *(That category is my
   signature error. The next quarter's inquiries should check for it
   first.)*
2. Which failures were rationalized rather than pre-committed? *(That
   count is my honesty score. It should fall over time.)*
3. Did any chapter of the Book accumulate two strikes? *(If yes: amend,
   log the amendment, date it.)*
4. What am I systematically over-thinking, and what am I
   under-thinking? *(The Second Question from the Final Page, answered
   with receipts instead of impressions.)*
