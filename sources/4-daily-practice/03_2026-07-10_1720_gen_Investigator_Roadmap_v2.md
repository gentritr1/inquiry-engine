# Investigator Roadmap v2

## Deliberate Practice for the Age of AI

> "The goal is not to know more. The goal is to build better mental
> models."

## The New Principle

AI makes answers cheap.

Learning is no longer limited by information.

Learning is limited by **prediction error**.

**Rule #1**

> Never let AI answer before you have committed to your own answer.

Every learning cycle follows:

Predict → Commit → Build → Fail → Explain → Compare → Revise → Journal

No exceptions.

------------------------------------------------------------------------

# The Three Goals

1.  Build better mental models.
2.  Improve calibration.
3.  Allocate attention to the highest-value questions.

------------------------------------------------------------------------

# Daily (45--60 minutes)

## 1. Prediction First (10 min)

Choose one technical or conceptual problem.

Write: - My current explanation. - Confidence (0--100%). - What would
change my mind?

Do NOT ask AI yet.

------------------------------------------------------------------------

## 2. Deliberate Struggle (20--30 min)

Attempt the solution yourself.

Examples: - Implement a cache. - Build a router. - Explain React
reconciliation. - Design a GraphQL cost limiter. - Solve an algorithm. -
Design an API.

Stop after the timebox.

Failure is expected.

------------------------------------------------------------------------

## 3. AI as Reviewer (10--15 min)

Only now ask AI:

-   Critique my reasoning.
-   Find hidden assumptions.
-   Destroy my design.
-   Show competing representations.

Prefer: "Do not solve immediately. First critique."

------------------------------------------------------------------------

## 4. Journal (5 min)

Record:

-   What prediction failed?
-   What assumption was wrong?
-   What representation changed?
-   What surprised me?
-   What rule would have prevented this?

------------------------------------------------------------------------

# Weekly

## Monday--Thursday

One architecture rediscovery daily.

Reverse engineer: - React - Git - SQLite - Redis - TypeScript -
GraphQL - HTTP - CSS Flexbox

Questions:

-   Original problem?
-   Naive solution?
-   Why did it fail?
-   Hidden assumption?
-   Representation change?
-   Invariant?
-   Tradeoffs?

------------------------------------------------------------------------

## Friday

Prediction Review

Resolve predictions.

Update calibration.

Open Failure Logs.

------------------------------------------------------------------------

## Weekend

One Engineering Essay

Examples:

Why React?

Why GraphQL?

Why Git?

Why CRDTs?

Why SQLite?

Focus on "Why", not "How".

------------------------------------------------------------------------

-   Darwin

-   Semmelweis

Only afterwards compare.

Goal:

------------------------------------------------------------------------

## Calibration Review

Bucket probabilities.

Did 80% predictions happen roughly 80% of the time?

Adjust confidence.

------------------------------------------------------------------------

## Method Review

Ask:

-   Did I overthink?
-   Did I underthink?
-   Did AI replace learning?
-   Did I predict before revealing?
-   Did I change my mind honestly?

# Reading Curriculum

Read with the Prediction Rule.

Before each chapter:

-   What do I think the answer is?
-   What problem is the author solving?

During:

-   What assumption changed?
-   What invariant emerged?
-   What representation changed?

After:

-   What changed my mind?
-   Which Book principle changed?
-   What experiment can I run this week?

Books:

1.  Thinking, Fast and Slow
2.  The Scout Mindset
3.  Superforecasting
4.  The Structure of Scientific Revolutions
5.  Thinking in Systems
6.  The Beginning of Infinity (critically)
7.  Algorithms to Live By
8.  Decisive

# AI Rules

✓ Reviewer ✓ Critic ✓ Historian ✓ Comparator ✓ Devil's Advocate

AI is NOT:

✗ First answer ✗ First design ✗ First implementation ✗ Replacement for
struggle

# North Star

Success is not:

"I solved more problems."

Success is:

"I built mental models that solve new problems."

The investigator's loop is:

Observe → Predict → Commit → Struggle → Compare → Revise → Journal →
Teach → Repeat

Reality remains the teacher. AI becomes the reviewer.
